# Aviation Edge

> Aviation Edge (Clearsky LTD) sells global aviation data through a single JSON/REST API and
> downloadable databases: real-time flight tracking, real-time / historical / future airport
> schedules, airline routes, NOTAMs, satellite tracking, and static airport, airline,
> aircraft, city, country, tax and timezone reference data. Every endpoint is an HTTPS GET
> under https://aviation-edge.com/v2/public and requires a paid subscription key passed as
> the `key` query parameter.

Generated 2026-09-04 by API Evangelist from this repository's artifacts and the provider's
published documentation. Aviation Edge does not serve an llms.txt of its own
(https://aviation-edge.com/llms.txt returns 404, probed 2026-09-04).

## Key facts

- Base URL: https://aviation-edge.com/v2/public
- Auth: API key in the `key` query parameter. No OAuth, no header auth, no scopes.
- Read-only: every published operation is a GET. No writes, so no idempotency and nothing to reverse.
- Errors: most failures return HTTP 200 with `{"error"|"message": ..., "success": false}`.
  /flightsHistory and /flightsFuture return HTTP 400 for a missing required parameter.
  An unknown path returns HTTP 404 with an HTML body.
- Rate limiting: a monthly call allowance per key (30,000 / 100,000 / 500,000 / unlimited).
  No RateLimit-* or Retry-After headers are sent — remaining quota is visible only in the dashboard.
- No free or trial key. The free tier was withdrawn; evaluation is a discounted first month.
- Times in responses are the local time of the airport, except NOTAM dates, which are UTC.

## Operations

Dynamic data
- GET /flights — real-time flight tracker. Filters: flightIata, airlineIata, depIata, arrIata,
  lat+lng+distance, status, limit (max 30000). Updates about every 5 minutes.
- GET /timetable — real-time airport departure or arrival timetable. Required: iataCode, type.
  Filters: airline_iata, status. Updates about every 15 minutes; covers roughly +/- 6 hours.
- GET /flightsHistory — historical airport schedules. Required: code, type. Filters: date_from,
  date_to (max 30-day range), airline_iata, flight_number, status. 1 year of history by default.
- GET /flightsFuture — future airport schedules. Required: type, iataCode, date. Filters:
  arr_iataCode, dep_iataCode. Up to 1 year ahead; the next 7 days are not served.
- GET /notams — airport and FIR NOTAMs. One of iata, icao or location is required. Filters:
  date_from, date_to.
- GET /satelliteDetails — satellite tracker. Filters: code (NORAD), launchYear, intldes,
  orbitalapogee, orbitalperigee, limit.

Static / reference data
- GET /routes — airline routes. Filters: departureIata, departureIcao, airlineIata, airlineIcao, flightNumber.
- GET /airportDatabase — airports. Filters: codeIataAirport, codeIso2Country.
- GET /airlineDatabase — airlines. Filters: codeIataAirline, codeIso2Country.
- GET /airplaneDatabase — individual airframes. Filters: numberRegistration, hexIcaoAirplane, codeIataAirline.
- GET /planeTypeDatabase — aircraft types. Filter: codeIataAircraft.
- GET /cityDatabase — cities. Filters: codeIataCity, codeIso2Country.
- GET /countryDatabase — countries. Filters: codeIso2Country, nameCountry.
- GET /taxDatabase — IATA aviation tax codes. Filter: codeIataTax.
- GET /timezoneDatabase — airport timezones.
- GET /autocomplete — location search. Required: city (the partial query string).
- GET /nearby — airports and cities near a coordinate. Required: lat, lng. Filter: distance.

## Cautions for agents

- A 200 response is not a success. Check `success` before parsing.
- Do not use this data for navigation or traffic advisories; the provider's own terms and FAQ
  rule that out, and only static data is covered by the SLA.
- Bulk pulls are quota-cheap (one call can return up to 30,000 records) but can be very large.
